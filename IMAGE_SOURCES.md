# Sweet Crumbs Image Sources

The Sweet Crumbs storefront uses locally stored images for the hero section, category cards, and product catalogue.

All images used by the website are stored inside the project:

- Category images: `assets/images/categories/`
- Product images: `assets/images/products/`

The images were originally sourced from Unsplash. The original source pages used for the image collection are listed below.

## Local Image Usage

The website references the images using local paths under `assets/images/`. Therefore, the product and category photographs do not need to be downloaded from Unsplash when the website is running.

An internet connection may still be required for other external resources used by the website, but the product and category images themselves are included in the project repository.
